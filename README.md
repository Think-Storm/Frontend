# ThinkStorm Frontend

## Description

This repository contains the frontend code and configuration for the ThinkStorm web application.

## Installation

To get started, install the required dependencies by running the following command:

```bash
npm install
```

## Running the Application

To run the frontend locally in development mode, use the following command:

```bash
npm run dev
```

The development server will start, and the frontend will be available at http://localhost:3000.
